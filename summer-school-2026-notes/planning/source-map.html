1.1 Local Layout

The root directory is not currently a git repository. Several important source folders are symlinks:

  • Elliot-SummerSchool -> ../Summer2024/
  • PowerlawCovariance -> ../../../PowerlawCovariance/
  • fourplusthree -> ../../../SGD/FixedCompute/
  • muonroot -> ../../../muonroot/

This matters for publishing: do not blindly initialize and publish this entire root as a GitHub repository. A clean notes repo should copy selected assets and cite the research sources, not commit the whole symlink farm.

1.3 Elliot-SummerSchool

Path: Elliot-SummerSchool/RMTandOptimization.tex

Role:

  • Best source for existing exposition style and broad RMT/optimization background.

Detected structure:

  • Background: tensors, calculus, resolvents, perturbation formulas, spectral mapping, Stieltjes transforms.
  • Concentration: martingales, subgaussian and subexponential concentration, Gaussian interpolation.
  • RMT: Dyson equations, deterministic equivalents, semicircle law, sample covariance matrices, deformed MP, spike examples, power-law spectrum, conjugate kernels.
  • Optimization: SGD, risks, streaming/online SGD, classical convergence, high-dimensional limits, correlated least squares, explicit risk curves, Volterra equations, homogenization of multipass SGD.

Use:

  • Pull notation and exposition style.
  • Use as background scaffolding for the light RMT interludes in modules 2 and 4.
  • Reuse proof-sketch patterns: resolvent to deterministic equivalent to risk curve.

1.4 PowerlawCovariance

Primary manuscript:

  • PowerlawCovariance/overleaf/6832219019e7681d398cecfb/main.tex
  • Title: Power Law Spectrum of the Random Feature Model

Core claim:

  • If input covariance has eigenvalues with power-law decay, the random feature covariance after Gaussian sketching and monomial activation inherits the same power-law exponent, up to logarithmic corrections.
  • Proof ingredients include tensor linear algebra, Wick chaos expansions, dyadic head-tail decompositions, lattice counting, and concentration.

Key sections:

  • Introduction.
  • Main results.
  • Discussion and numerical experiments.
  • Warm up: linear case.
  • Higher order case.
  • Principal term.
  • Subleading terms and Wick chaoses.
  • Appendix: concentration, auxiliary lemmas, Wick products, lattice point counting, CIFAR-10 experiments.

Experiment notes:

  • PowerlawCovariance/CIFAR_experiment/README.md
  • PowerlawCovariance/CIFAR_experiment/figure_notes.md

Useful figures:

  • PowerlawCovariance/overleaf/6832219019e7681d398cecfb/figures/cifar10_covariance_eigenvalues.pdf
  • PowerlawCovariance/overleaf/6832219019e7681d398cecfb/figures/figure1_plrf_and_tanh.pdf

1.5 fourplusthree

Primary manuscript:

  • fourplusthree/Fixed_Compute_Final/arxiv/arxiv_version_new.tex
  • Title: 4+3 Phases of Compute-Optimal Neural Scaling Laws

Core claim:

  • In the Maloney-Roberts-Sully three-parameter solvable scaling model, SGD loss curves can be represented across iteration counts, then optimized over model parameter count under compute. The phase diagram has 4 phases plus 3 subphases governed by model capacity, optimizer noise, and feature embedding.

Key sections:

  • Problem setup: SGD on Power-law Random Features.
  • Learning dynamics of SGD.
  • Forcing function and kernel function.
  • The 4 Phases.
  • Compute-optimal curves.
  • Spectrum of the sketched kernel: random matrix theory.
  • Self-consistent approximation for the resolvent.
  • Asymptotics and experimental results.

Useful figures:

  • fourplusthree/Fixed_Compute_Final/figures/Spectrum.pdf
  • fourplusthree/Fixed_Compute_Final/figures/scalingfig4.pdf

  • fourplusthree/Presentation/ChinchillaLines.pdf
  • fourplusthree/Presentation/alphabetaVolterraOnly.pdf

Use:

  • Module 2 backbone.
  • Main place to connect power-law covariance to Chinchilla-style compute thinking.
  • Main place for the first substantial RMT flavor: sample covariance, deterministic equivalent, and the Volterra risk equation.

1.6 momentum-fixed-compute

Primary manuscript:

  • momentum-fixed-compute/neurips_paper.tex
  • Title: Dimension-adapted Momentum Outscales SGD

Core claim:

  • Classical constant momentum does not improve scaling exponents over SGD in the PLRF setting, but DANA-style dimension/data-adapted Nesterov schedules can improve loss and compute-optimal scaling exponents across a broad region.

1.7 danastar

Primary manuscript:

  • danastar/arXiv_version/arxiv_paper.tex
  • Title: Logarithmic-time Schedules for Scaling Language Models with Momentum

Core claim:

  • Large-scale language model training can benefit from time-varying schedules for AdamW-style beta parameters and weight decay. ADANA and hardened variants apply log-time scheduling with damping; reported compute efficiency gains are measured against tuned AdamW, with experiments from 45M to 2.6B parameters.

1.8 muonroot

Primary manuscript:

  • muonroot/overleaf-neurips/neurips_2026.tex
  • ArXiv variant: muonroot/overleaf-neurips/arXiv_version/arxiv_version_main.tex
  • Title: Phases of Muon: When Muon Eclipses SignSGD

Core claim:

  • Muon-like spectral optimizers can be modeled through stochastic SignSVD on a matrix-valued least squares problem. SignSVD behaves like square-root preconditioning at large batch, but small eigenmodes can revert toward SGD-like behavior at small batch. In power-law covariance, the alpha-beta plane has phases favoring SignSVD, SignSGD, or a trade-off.

Key sections:

  • Model setup and stochastic spectral algorithms.
  • Learning curves and exact dynamics.
  • SignSVD and SignSGD in the isotropic setting.
  • Anisotropic output covariance.
  • Power-law specialization.
  • Time to epsilon-approximate solution.
  • Appendices: RMT setup, derivations, half-anisotropic model, power-law analysis, Volterra equation, momentum ablation.
